# StrayAnimals
一個使用政府API查詢台灣流浪動物的App

## 政府的動物認領養 Open Data URL
https://data.moa.gov.tw/open_detail.aspx?id=QcbUEzN6E6DL

## 預計使用：
1. MVVM
2. Combine
3. Code UI

## 畫面：
1. List (CollectionView 使用 UICollectionViewCompositionalLayout)
2. Information

## 額外使用
1. 圖片壓縮代理: ImageKit.io (Open Data Response 的圖片過於龐大 768 x 768，下載速度過慢)

## 圖片來源
1. Lucide
2. Bootstrap Icons
3. Phosphor Icons
